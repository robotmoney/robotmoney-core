# ExclusionLedgerFactory

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/2b5d9c4acd4cb83f9e0296cb55ac7ac1f5bacbf6/contracts/ExclusionLedgerFactory.sol)

**Title:** ExclusionLedgerFactory

Creates the `ExclusionLedger` of one `RobotMoneyVault` proxy. Stateless; deployed once
per chain by CREATE2 in the libs stage.

<i>

Why it exists: before ADR-0014 the vault constructor ran `new ExclusionLedger(asset)`, which
is initcode. Behind a proxy that line would sit in `initialize`, an ordinary function, and
embed the ledger's ~5.9 KB creation code in the vault's EIP-170-tight runtime. The factory
holds that creation code instead. The ledger is bound to `msg.sender`, so a vault can only
ever create its own ledger; the vault initializer checks `VAULT() == address(this)`.

</i>

## Functions

<a id="create-ierc20"></a>

### create

Create the exclusion ledger of the calling vault.

```solidity
function create(IERC20 asset) external returns (ExclusionLedger ledger);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| asset | `IERC20` | The vault's asset (USDC). |

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| ledger | `ExclusionLedger` | The new ledger, whose `VAULT()` is `msg.sender`. |

## Events

### ExclusionLedgerCreated

A ledger was created for `vault`.

```solidity
event ExclusionLedgerCreated(address indexed vault, address indexed ledger, address asset);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| vault | `address` | The calling vault: the ledger's only writer. |
| ledger | `address` | The new ledger. |
| asset | `address` | The vault's asset the ledger holds and pays. |
