**Title:** UniswapV3ExactOutSwapAdapter

Test copy of the production `UniswapV3SwapAdapter` (step 3d): it inherits the production exact-input
`swap` and `twapPrice` unchanged and adds `swapExactOut`, whose `maxAmountIn` is the per-swap price limit
of the fund's pro-rata purchase (check 9). The production adapter does not change (eng plan §3.3).
Inheriting instead of copying keeps the production code paths byte-identical in behaviour; the runtime
code hash differs, so the harness allowlists this copy's hash.

### swapExactOut

Buy exactly `amountOut` of `tokenOut` for at most `maxAmountIn` of `tokenIn`, paid to `recipient`.
Pulls `maxAmountIn` from the caller, sends the unused input back to the caller, and resets its
allowance to the venue to 0. Reverts if the venue needs more than `maxAmountIn` or the deadline passed.

<i>

Pulls `maxAmountIn` from the caller, approves the router for exactly that, calls `exactOutputSingle`
(no sqrt price limit, so the router delivers exactly `amountOut` or reverts), resets the allowance to 0
(ADP-5), and returns `maxAmountIn − amountIn` to the caller. The router itself reverts when it needs more
than `amountInMaximum` ("STF"/"Too much requested"), so no input above the limit is ever spent.

</i>

```solidity
function swapExactOut(
        address tokenIn,
        address tokenOut,
        uint24 fee,
        uint256 amountOut,
        uint256 maxAmountIn,
        address recipient,
        uint256 deadline
    ) external returns (uint256 amountIn);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| tokenIn | `address` |  |
| tokenOut | `address` |  |

| amountOut | `uint256` |  |

### isFixedFeePool

True when `pool` is a fixed-fee pool recognized by this adapter (e.g. Uniswap V3).

<i>

Uniswap V3 pool fees are immutable at construction (`E43`, §4.5 rule 6). Checks code presence, a
valid `fee()` in `(0, 1_000_000)` pips, and the 7-field (224-byte) Uniswap V3 `slot0()` ABI so an
Aerodrome Slipstream `CLPool` (whose mutable-fee `slot0()` returns 6 words / 192 bytes) is rejected.

</i>

```solidity
function isFixedFeePool(address pool) external view returns (bool);
```
