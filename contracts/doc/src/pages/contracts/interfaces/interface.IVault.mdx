# IVault

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/c50698bf07f9dde361beec76d529ece2593f1efc/contracts/interfaces/IVault.sol)

**Title:** IVault

The read surface `rmpc` uses on any deployed vault (issue #1464).
It is the compiler-owned source of `clients/rust-payment-client/abi/IVault.json`,
generated by `.github/scripts/generate_abi_bindings.sh` and drift-gated by suite-16.
It replaces the hand-maintained `MockVault.json`, which read real vaults through
a "TEST FIXTURE only" contract's ABI plus a hand-added `depositsPaused()`.

<i>

INTERFACE ONLY. No deployed vault inherits this file: vault bytecode and
inheritance are frozen, and inheriting an interface changes compiled metadata.
Every function below is a plain ERC-20 / ERC-4626 read, or the vault's public
`depositsPaused` flag. A selector rename in a real vault is caught by the
`rmpc` selector test and the fork e2e suite, not by the compiler.

</i>
