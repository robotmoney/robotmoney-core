# IVenueLiquidityAdapter

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/3734576ecc686bcb32706470eab06d5adc06a3f5/contracts/interfaces/IVenueLiquidityAdapter.sol)

Optional withdrawal liquidity probe for a strategy adapter.

<i>

Adapters implementing this interface advertise its interface ID through ERC-165.

</i>

## Functions

<a id="withdrawalliquidity"></a>

### withdrawalLiquidity

```solidity
function withdrawalLiquidity() external view returns (bool open, uint256 available);
```

**Returns**

| Name | Type | Description |
| ---- | ---- | ----------- |
| open | `bool` | Whether the venue permits withdrawals under current conditions. |
| available | `uint256` | The maximum underlying the adapter can withdraw immediately. |
