# FlowParams

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/30d56e3e3fa551fc97da4f6d7e277f769b2d1a20/contracts/FlowTypes.sol)

Every queue parameter of proposal §5.9.5 and §5.11 (D39, E39, E51).
`ADMIN_ROLE` sets it through the timelock inside the hard bounds above.

```solidity
struct FlowParams {
    uint32 epochLength;
    uint32 settleWindow;
    uint32 minHold;
    uint32 keeperGrace;
    uint16 maxEpochFlowBps;
    uint128 epochFlowFloorUsdc;
    uint16 maxSharePriceMoveBps;
    uint16 maxRoll;
    uint128 minRequestUsdc;
    uint32 maxFreeze;
    uint8 slices;
    uint8 quorum;
    uint16 dispersionBps;
    uint16 refBandBps;
    uint16 legBandBps;
    uint32 sequencerGrace;
    uint16 usdcPegBandBps;
    uint16 maxLendRateGrowthBps;
    uint32 cancelBuffer;
    uint32 maxPause;
    uint16 matchBandBps;
}
```

**Properties**

| Name | Type | Description |
| ---- | ---- | ----------- |
| epochLength | `uint32` | Epoch length and the clock-time period of each flow cap (§5.9.5: 6 h). |
| settleWindow | `uint32` | Wait after an epoch closes before it may settle; also the TWAP window (1 h). |
| minHold | `uint32` | Hold of deposit shares after their settlement (1 h, D4-11). |
| keeperGrace | `uint32` | Retired in Step 3f (`settle()` is KEEPER_ROLE-only, E34); kept at index 3<br/>for storage and tuple compatibility. |
| maxEpochFlowBps | `uint16` | Each side's cap per period, in bps of NAV at the feeds (500, E20). |
| epochFlowFloorUsdc | `uint128` | Each side's cap is at least this (250 000 USDC, E20). |
| maxSharePriceMoveBps | `uint16` | Share-price breaker per epoch passed since the last settlement (1 000, check 6). |
| maxRoll | `uint16` | Epochs after which an unfilled deposit expires / redemption notice unlocks (8, E18/E40). |
| minRequestUsdc | `uint128` | Least request size (100 USDC, E11); a whole-balance redemption is exempt. |
| maxFreeze | `uint32` | Longest freeze of one settlement's deposit shares (7 days, E17). |
| slices | `uint8` | Equal slices of `settleWindow` for the TWAP median (12, E6). |
| quorum | `uint8` | Slices that must sit within `dispersionBps` of the median (9, check 3). |
| dispersionBps | `uint16` | Slice band around the median (100, check 3). |
| refBandBps | `uint16` | TWAP against feed band (90, check 4). |
| legBandBps | `uint16` | Per-swap limit band around the stricter of feed and TWAP (100, checks 8 and 9). |
| sequencerGrace | `uint32` | Time the sequencer must have been up (1 h, check 2). |
| usdcPegBandBps | `uint16` | USDC / USD band around 1 (50, check 2). |
| maxLendRateGrowthBps | `uint16` | Most growth per day of a venue's rate per unit (10, check 5). |
| cancelBuffer | `uint32` | Seconds before epoch close when `cancel` locks (15 min default, D39). |
| maxPause | `uint32` | Duration (and cooldown for `pauseQueue`/`pauseRebalance`) of self-expiring pauses (72 h, E39). |
| matchBandBps | `uint16` | Match band (plan 8.5 fallback): the whole match books only when the TWAP NAV sits within<br/>this many bps of the feed NAV. Tighter than `refBandBps`. Outside it the round nets at<br/>the feed price with no match. Must be at most `refBandBps`. |
