# RouteHarness

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/32c74b4101392888212aa04d9da684c28a4aa416/contracts/test/RobotMoneyVaultRouteDeposit.t.sol)

`_routeDeposit` makes, without the surrounding `deposit()` NAV reads.
