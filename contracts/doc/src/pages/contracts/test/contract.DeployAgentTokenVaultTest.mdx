# DeployAgentTokenVaultTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/77c18cc501b58598887747e7c5881b622e1b4fe3/contracts/test/DeployAgentTokenVault.t.sol)

**Inherits:** [BasketDeployFixture](/contracts/test/helpers/abstract.BasketDeployFixture)

rmAGENT script: paused and registered at launch, holding RM on the shipped config
(an empty list is also supported). The same script adds an asset
from one config entry (adapter deployed, code hash allowed, `addAsset` called).
