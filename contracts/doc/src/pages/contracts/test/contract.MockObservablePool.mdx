# MockObservablePool

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/294ae939cc4db43ac7ec7bac05d27e475246f588/contracts/test/TwapTickMath.t.sol)

**Inherits:** [IObservablePool](/contracts/interfaces/interface.IObservablePool)

<i>

Minimal mock implementing the `IObservablePool` surface. `observe()`
returns a pre-set tickCumulatives pair so `meanTick` can be exercised
across boundary inputs without a live pool.

</i>
