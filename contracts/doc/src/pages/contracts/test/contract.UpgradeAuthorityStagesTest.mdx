# UpgradeAuthorityStagesTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/77c18cc501b58598887747e7c5881b622e1b4fe3/contracts/test/UpgradeAuthorityStages.t.sol)

**Inherits:** [SafeGovernance](/contracts/test/helpers/abstract.SafeGovernance)

Issue 1808, the timelock-last stage order. Every proxy names the CREATE2 address of the
Safe-proposer timelock from its first block; the timelock stage deploys the timelock
there and refuses any proxy that names another authority. Until then nobody (the
deployer included) can upgrade or freeze: there is no interim deployer authority.

<a id="test_nointerimauthority_thenthehandoverdeploysthepredictedtimelock"></a>

### test_noInterimAuthority_thenTheHandoverDeploysThePredictedTimelock

Before the timelock stage the authority has no code and nobody can upgrade or
freeze; the stage deploys the timelock at exactly the address every proxy named,
and from then on the Safe, through it, can.

```solidity
function test_noInterimAuthority_thenTheHandoverDeploysThePredictedTimelock() public;
```

### test_handover_refusesAProxyNamingAnotherAuthority

### test_aTimelockAlreadyAtThePrediction_isReused

### test_stageEnv_isRequired_andNamesThePrediction

`upgradeable` or `frozen`. Every one is required; nothing has a default.
