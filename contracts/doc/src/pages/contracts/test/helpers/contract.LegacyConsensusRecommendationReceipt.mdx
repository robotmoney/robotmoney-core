# LegacyConsensusRecommendationReceipt

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/77c18cc501b58598887747e7c5881b622e1b4fe3/contracts/test/helpers/LegacyConsensusRecommendationReceipt.sol)

**Inherits:** [AdminFloorAccessControl](/contracts/lib/abstract.AdminFloorAccessControl), ReentrancyGuardUpgradeable, [GovernedUUPS](/contracts/lib/abstract.GovernedUUPS)

**Title:** LegacyConsensusRecommendationReceipt

A faithful copy of the v0.5.0 receipt's state and write surface, used ONLY to build a
populated proxy that the migration test upgrades to the current receipt. Its storage
layout is identical to `ConsensusRecommendationReceipt`: `gateway`, `icPolicy`, the
receipt log and the index map, in that order, behind the same bases.
