# PausableComet

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/77c18cc501b58598887747e7c5881b622e1b4fe3/contracts/test/helpers/RefusingVenues.sol)

<i>

1:1 Compound V3 Comet whose pause guardian pauses supply (`isSupplyPaused`) and withdraw
(`isWithdrawPaused`) separately: the paused call reverts `Paused`, as Comet does.

</i>
