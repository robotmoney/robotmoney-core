# ForkSelect

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/04c494d92ce87df3b9ba252c17541e08e28fdf97/contracts/test/helpers/ForkSelect.sol)

Fork selection for tests that need real Base state. The golden-fork runner serves the
pinned fixture on 127.0.0.1:8545 and sets FORK_REQUIRED=1: an unreachable endpoint then
fails the test. Without FORK_REQUIRED an unreachable endpoint skips the test, so the plain
unit run stays green on a machine with no chain.
