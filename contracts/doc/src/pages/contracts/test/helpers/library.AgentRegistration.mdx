# AgentRegistration

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/5be2e7be63d58c4a38ea155357305b04ecf381b7/contracts/test/helpers/AgentRegistration.sol)

**Title:** AgentRegistration

Test helper that registers a gateway agent the only way the gateway
allows (ACL-9): agent consent, owner commit, one block, owner reveal.
The gateway has no admin shortcut, so every test that needs a
registered agent goes through here.

<i>

Canonical: docs/architecture.md section 5.2, docs/technical/smart-contract-invariants.md ACL-9.

</i>
