# CoreStages

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/04c494d92ce87df3b9ba252c17541e08e28fdf97/contracts/test/helpers/CoreStages.sol)

Runs the core stage scripts in process, in production order:
libs, vault, registry, router, gateway. Tests use it where a single deploy script used to be called. Agent authorization is part of the gateway stage and runs
after the gateway exists. The IC policy stage is a separate script that tests call
when they need it.

<i>

Not a Script: it carries no cheatcode state of its own. The stage scripts it creates
are the production scripts. `stages` is the order the run followed, for tests that
assert the order.

</i>
