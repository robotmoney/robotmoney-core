# BasketDeployFixture

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/aae683920cd57dc96d920c3e2d788e226f098aef/contracts/test/helpers/BasketDeployFixture.sol)

**Inherits:** Test

<i>

Shared setup for the three basket vault script tests. The scripts run in process under a
prank of `deployer`. Pools are `ConstPool` instances: a unit test has no live Uniswap.
A config-file test etches the mock code at each configured pool address, so the script
reads the real `config/*.json` and the assertions compare chain state to that file.

</i>
