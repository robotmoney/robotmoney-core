# ConstPool

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/04c494d92ce87df3b9ba252c17541e08e28fdf97/contracts/test/helpers/BasketDeployFixture.sol)

<i>

Uniswap V3 pool double whose every field is an immutable or a constant, so its runtime code
can be etched at a real pool address with no storage. 1:1 TWAP, deep cardinality and
liquidity, `fee()` as constructed.

</i>
