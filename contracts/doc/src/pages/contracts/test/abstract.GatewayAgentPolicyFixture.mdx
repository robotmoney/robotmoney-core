# GatewayAgentPolicyFixture

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/5be2e7be63d58c4a38ea155357305b04ecf381b7/contracts/test/GatewayAgentPolicyAuthorization.t.sol)

**Inherits:** Test

<i>

Shared fixture: a gateway with two ADMIN_ROLE holders (`admin`, the
constructor admin that also holds DEFAULT_ADMIN_ROLE, and `adminOwner`)
and a permissionless account (`user`). Every account registers agents the
same way: agent consent, owner commit, owner reveal.

</i>
