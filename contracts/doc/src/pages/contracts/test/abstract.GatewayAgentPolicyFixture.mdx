# GatewayAgentPolicyFixture

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/92c8c84ea872a76927a29be10ee9d58fbfd83a8c/contracts/test/GatewayAgentPolicyAuthorization.t.sol)

**Inherits:** Test

<i>

Shared fixture: a gateway with two ADMIN_ROLE holders (`admin`, the
constructor admin, and `adminOwner`, who owns agents in these tests)
and a permissionless account (`user`) that authorizes through
commit/reveal. Agents made with `_keyed` have a known key, so a
permissionless reveal can carry the agent's consent (issue #1791).

</i>
