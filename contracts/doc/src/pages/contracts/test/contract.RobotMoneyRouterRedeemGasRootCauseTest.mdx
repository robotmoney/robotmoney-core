# RobotMoneyRouterRedeemGasRootCauseTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/32c74b4101392888212aa04d9da684c28a4aa416/contracts/test/RobotMoneyVaultRedeemGasRootCause.t.sol)

**Inherits:** Test

Multi-leg estimate-then-include on the fork (core 1482 review). The core stage stack
plus two more vaults built by the same DeployVault script, all on the real Aave,
Compound and Moonwell venues. Estimate in the accrued-this-block state, include one
block later at exactly that limit, through the router and through the gateway.
