# RwaVaultB20ForkTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/aff4c40a1ddd0d52759d7846c6e06e93e8a10512/contracts/test/RwaVaultB20Fork.t.sol)

**Inherits:** Test

Fork test for core 1500: the four Coinbase B20 tokens join rmRWA through a real
TimelockController at the production delay, then USDC deposits and redeems with all
five assets held. Runs on the Twin chain (FORK_RPC_URL). Unset, it skips with a named
reason, and CI refuses a run in which no test executed.
