# FundDecimalsForkTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/9362075c383ceca56e2c885e2aa4e5fb76d7bd97/contracts/test/FundDecimalsFork.t.sol)

**Inherits:** Test

The live fund proxy stores underlying decimals 6, so an in-place swap to the new implementation (the
OpenZeppelin `decimals()` default) reports 24 and moves no balance. The swap is a local `vm.store` on the
fork, never a transaction. Skips only while FORK_RPC_URL is unset (see ForkSelect).
