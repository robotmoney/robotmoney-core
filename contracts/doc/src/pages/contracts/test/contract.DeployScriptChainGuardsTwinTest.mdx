# DeployScriptChainGuardsTwinTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/04c494d92ce87df3b9ba252c17541e08e28fdf97/contracts/test/DeployScriptChainGuardsTwin.t.sol)

**Inherits:** Test

On the Twin chain (918453) the strict chain guard does not fire for an unset
EXPECTED_CHAIN_ID: each script's `run()` either fails on a later required input or
runs on, but never with the 8453 guard message. The 8453 side (guard fires) is
DeployScriptChainGuards.t.sol, so each script is pinned on both sides of the floor.

<i>

No test sets an env var, so there is no race with the parallel 8453 contract.

</i>

## Constants

### GUARD_REVERT

```solidity
bytes32 internal constant GUARD_REVERT = keccak256(
        abi.encodeWithSignature(
            "Error(string)", "EXPECTED_CHAIN_ID must be set to 8453 on Base mainnet"
        )
    );
```
