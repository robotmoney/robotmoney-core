# QuoteCeilingVault

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/77c18cc501b58598887747e7c5881b622e1b4fe3/contracts/test/PortfolioRouterLegAvailability.t.sol)

**Inherits:** ERC20

<i>

1:1 router leg whose `previewDeposit` and `deposit` revert above `ceiling` while `maxDeposit` stays open, so only the
router's quote check can drop it. Counts `deposit` calls so a test can prove a dropped leg was never called.

</i>

<a id="decimals"></a>

### decimals

<i>

Returns the number of decimals used to get its user representation.
For example, if `decimals` equals `2`, a balance of `505` tokens should
be displayed to a user as `5.05` (`505 / 10 ** 2`).

Tokens usually opt for a value of 18, imitating the relationship between
Ether and Wei. This is the default value returned by this function, unless
it's overridden.

NOTE: This information is only used for _display_ purposes: it in
no way affects any of the arithmetic of the contract, including
`IERC20` and `IERC20`.

</i>
