# DeployTimelockRunEntrypointBase

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/77c18cc501b58598887747e7c5881b622e1b4fe3/contracts/test/DeployTimelock.t.sol)

**Inherits:** [SafeGovernance](/contracts/test/helpers/abstract.SafeGovernance)

`run()` drives its own body, `_runFrom`, through
the broadcast path against a core stack (CoreStages). Every env var it
reads carries a prefix only this test sets, because env vars are
process-wide and forge runs tests in parallel.
