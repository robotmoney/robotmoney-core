# RedeployProtocolAssetVaultTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/77c18cc501b58598887747e7c5881b622e1b4fe3/contracts/test/RedeployProtocolAssetVault.t.sol)

**Inherits:** [BasketDeployFixture](/contracts/test/helpers/abstract.BasketDeployFixture), [SafeGovernance](/contracts/test/helpers/abstract.SafeGovernance)

Single-vault redeploy of rmPROTO into a live deployment (issue 1796).
The deployment state is the Deploy 2 shape: registry and router governed by a timelock, four router-eligible vaults,
the default split 8550 / 525 / 575 / 350. The new vault comes from the redeploy script. The govern row's batch is
replayed call by call from the timelock, so the order of retire against migrateEligibility is checked on the real contracts.
