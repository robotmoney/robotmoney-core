# DeployInputsHarness

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/58e088ac53759285525112de9eee810ef2094dce/contracts/test/DeployMainnetInputs.t.sol)

**Inherits:** [DeployVault](/contracts/script/contract.DeployVault)

<i>

Exposes the script's internal env readers and deploy step. Every test below uses a
prefix of its own, because env vars are process-wide and forge runs test contracts
in parallel (see the note in Deploy.t.sol on the ADMIN_ADDRESS race).

</i>
