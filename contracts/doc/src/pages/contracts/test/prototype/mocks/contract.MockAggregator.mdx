**Title:** MockAggregator

A Chainlink `AggregatorV3Interface` stand-in whose round the test sets. The harness places its runtime
code at each real Base feed address with `vm.etch` (no constructor, no immutable, so the etched code works
and no deployer nonce is used), then writes the round with `setRound`. `FeedLib` reads only `decimals()`
and `latestRoundData()`; `description()` is here for probes.

Every storage field is a full word and every read follows a `setRound`, so a write never needs a read
first (no packed field), and on a recorded feed account the fixture coverage check sees writes first.

## Functions

<a id="setround-uint8-int256-uint256-uint256"></a>

### setRound

Set the latest round: a complete round (`answeredInRound == roundId == 1`).

```solidity
function setRound(uint8 decimals_, int256 answer_, uint256 startedAt_, uint256 updatedAt_)
        external;
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| decimals_ | `uint8` | The feed's decimals (8 for a price feed, 0 for the sequencer feed). |
| answer_ | `int256` | The answer in `decimals_` (sequencer feed: 0 = up, 1 = down). |
| startedAt_ | `uint256` | Round start (sequencer feed: when the current status began). |
| updatedAt_ | `uint256` | Round update time (the age `FeedLib.read` checks). |
