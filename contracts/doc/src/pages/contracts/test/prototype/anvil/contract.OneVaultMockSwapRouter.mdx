# OneVaultMockSwapRouter

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d26015d044a6162bbd93106a89523fa140073356/contracts/test/prototype/anvil/OneVaultKeeperAnvil.s.sol)

Test-only swap router with the two entry points the basket swap adapter calls: exact input (the fund's sale
and buy legs through the adapter's inherited `swap`) and exact output. It fills at one for one and pays USDC
from its own balance, which the deploy funds.
