# ThinStretchPool

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/ReviewFixes.t.sol)

A pool whose in-range liquidity is `L` except for one stretch `[thinFrom, thinTo)` (seconds before now) at
liquidity 1, the way Uniswap V3 accumulates `secondsPerLiquidity` (`dt × 2^128 / max(1, L)`). Constant
tick 0.
