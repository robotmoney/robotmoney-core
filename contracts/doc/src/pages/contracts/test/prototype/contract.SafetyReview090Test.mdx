# SafetyReview090Test

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/0ab4b2ac1ec333cb0ac75c1007001e41c97d9264/contracts/test/prototype/SafetyReview090.t.sol)

**Inherits:** [FlowQueueBase](/contracts/test/prototype/abstract.FlowQueueBase)

**Title:** SafetyReview090Test

Proof tests for the agy safety review of 0.9.0. Each test states the failure the review claims as a
property that must hold. A test that failed before its fix is the proof the finding was real.
