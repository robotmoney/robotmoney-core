# AuctionExecutorTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/baseline/AuctionExecutor.t.sol)

**Inherits:** [BaselineHarness](/contracts/test/prototype/baseline/abstract.BaselineHarness), [IAuctionFiller](/contracts/test/prototype/baseline/src/interface.IAuctionFiller)

Phase 3c: the auction executor behind `executeStep`. The test contract is the filler. It mints what
it owes, so these tests check the auction's rules, not a solver's sourcing (the sim models that).

<a id="test_fillatopen_paystwappluspremium_tothefund"></a>

### test_fillAtOpen_paysTwapPlusPremium_toTheFund

<i>

A fill in the open's block pays the start price: the leg's TWAP quote plus the premium. The fund
gets the tokens, the filler gets the fund's USDC, and the executor keeps nothing (RB-3).

</i>

```solidity
function test_fillAtOpen_paysTwapPlusPremium_toTheFund() public fixtureCovered;
```

<a id="test_owed_decayslinearly_tothetwapfloor"></a>

### test_owed_decaysLinearly_toTheTwapFloor

<i>

The owed amount falls linearly from TWAP + premium toward the swap path's TWAP floor. Fills run at
0, D/4 and D/2 (a wETH fill at the floor costs about `maxStepCostBps`, so RB-4 may refuse it). The
curve itself reaches the floor at DURATION, stays there, and is never below it.

</i>

```solidity
function test_owed_decaysLinearly_toTheTwapFloor() public fixtureCovered;
```

<a id="test_underpay_revertsthewholefill_withoutbackoff"></a>

### test_underpay_revertsTheWholeFill_withoutBackoff

<i>

A filler that pays one unit short: the leg reverts, so the whole fill reverts. Nothing trades, no
step is recorded and no asset backs off. A filler cannot book a fake failure.

</i>

```solidity
function test_underpay_revertsTheWholeFill_withoutBackoff() public fixtureCovered;
```

<a id="test_openandfill_lifecycle"></a>

### test_openAndFill_lifecycle

<i>

Open needs a step the Rebalancer would take now, and one auction at a time. Fill needs a live
auction. After 2 × DURATION the auction lapses and can be opened again. After a fill the cooldown
blocks the next open (RB-5).

</i>

```solidity
function test_openAndFill_lifecycle() public fixtureCovered;
```

function test_marketDeviation_afterOpen_fillReverts() public fixtureCovered;

<a id="test_fillatdespxafloor_hitsthestepcostcap"></a>

### test_fillAtDespxaFloor_hitsTheStepCostCap

<i>

RB-4 still binds inside a fill. deSPXA's TWAP floor sits 200 bps under TWAP, past the 50 bps step cost
cap. A fill at that floor makes the fund revert StepCostExceeded. The whole fill reverts, nothing moves
and no backoff is booked. A fill early on the curve, above the cap, trades.

</i>

```solidity
function test_fillAtDespxaFloor_hitsTheStepCostCap() public fixtureCovered;
```
