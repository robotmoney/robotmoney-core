# TargetVectorTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/baseline/TargetVector.t.sol)

**Inherits:** [BaselineHarness](/contracts/test/prototype/baseline/abstract.BaselineHarness)

RB-9: a target vector names every active asset exactly once and sums to 10 000. Each refused vector
reverts with its own error through all three doors (`applyReceipt`, `setTarget`, `previewPlan`). A
refused `applyReceipt` releases nothing, so the same receipt then applies with its valid vector.
