# SizeGateTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/baseline/SizeGate.t.sol)

**Inherits:** [BaselineHarness](/contracts/test/prototype/baseline/abstract.BaselineHarness)

One-vault experiment (plan Step 2.2, gate G1): the fund implementation and the rebalancer
implementation each deploy with at least 1 KB of headroom under EIP-170 (24,576 bytes).
Sizes are read from the code the harness actually deployed (the ERC-1967 implementation
behind each proxy), compiled with the repo's production optimizer settings.

<i>

EIP-170 runtime code limit.

</i>

```solidity

```

### G1_MAX

<i>

G1 headroom: 1 KB under the EIP-170 limit.

</i>

```solidity
uint256 internal constant G1_MAX = EIP170_LIMIT - 1024;
```
