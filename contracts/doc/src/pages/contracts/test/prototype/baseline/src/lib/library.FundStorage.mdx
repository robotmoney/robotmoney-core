[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/baseline/src/lib/FundStorage.sol)

**Title:** FundStorage

ERC-7201 namespaced location of `FundState` (`robotmoney.storage.RobotMoneyFund`), so the fund's
own state can never collide with the OpenZeppelin upgradeable namespaces behind `GovernedUUPS`.
