# IFundEvents

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/baseline/src/FundTypes.sol)

**Title:** IFundEvents

Events and errors shared by the fund and the rebalancer. Both inherit this interface
(through IRobotMoneyFund / IRebalancer), so tests can `emit IFundEvents.X(...)`.

## Events

### PlanOpened

A plan opened (§5.1 step 3). Emitted after the previous live plan's
`PlanStatusChanged(..., Superseded)`.

```solidity
event PlanOpened(
        uint256 indexed planId,
        bytes32 indexed receiptId,
        uint16[] startBps,
        uint16[] endBps,
        uint64 startTime,
        uint64 endTime,
        uint256 turnoverUsdc,
        uint256 costBudget
    );
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| planId | `uint256` |  |
| receiptId | `bytes32` |  |
| startBps | `uint16[]` |  |
| endBps | `uint16[]` |  |
| startTime | `uint64` |  |
| endTime | `uint64` |  |
| turnoverUsdc | `uint256` |  |
| costBudget | `uint256` |  |

### RebalanceStep

A step executed. `sellPathBps` / `buyPathBps` are the legs' path targets at the
step's timestamp (idle's path for an IDLE_INDEX leg).

```solidity

        uint256 indexed planId,
        uint256 sellIndex,
        uint256 buyIndex,
        uint256 notionalUsdc,
        uint256 amountIn,
        uint256 amountOut,
        uint256 cost,
        uint256 sellPathBps,
        uint256 buyPathBps
    );
```

**Parameters**

| Name | Type | Description |

### RebalanceStepSkipped

`step()` returned without trading. `sellIndex` / `buyIndex` are the chosen legs when
known, else IDLE_INDEX. `detail`: asset index for MarketDeviation, revert selector
for StepFailed, the notional for BelowMinStep, the seconds remaining for Cooldown,
0 otherwise.

```solidity
event RebalanceStepSkipped(
        uint256 indexed planId,
        SkipReason reason,
        uint256 sellIndex,
        uint256 buyIndex,
        uint256 detail
    );
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| planId | `uint256` |  |
| reason | `SkipReason` |  |
| sellIndex | `uint256` |  |
| buyIndex | `uint256` |  |
| detail | `uint256` |  |

### TargetAssetMissing

A target vector leaves out the active asset `asset`. An explicit 0 is required to
sell an asset, so a vector can never sell one by forgetting it.

```solidity

```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| asset | `address` |  |

### TargetSumInvalid

A target vector's weights do not sum to 10 000. A single weight above 10 000 reverts
at once and reports that weight.

```solidity
error TargetSumInvalid(uint256 sum);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| sum | `uint256` |  |
