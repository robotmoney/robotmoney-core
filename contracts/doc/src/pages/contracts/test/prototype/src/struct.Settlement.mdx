# Settlement

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/src/FlowTypes.sol)

One `settle` call that traded (proposal §5.9.3 check 12 "record").

```solidity
struct Settlement {
    uint64 time;
    address settler;
    uint256 depositBoundPrice;
    uint256 redeemBoundPrice;
    uint256 usdcIn;
    uint256 sharesMinted;
    uint256 sharesBurned;
    uint256 usdcOut;
    uint64 frozenUntil;
    bool returnAllowed;
    uint64 holdEndsAt;
}
```

**Properties**

| Name | Type | Description |
| ---- | ---- | ----------- |
| time | `uint64` | `block.timestamp` of the settlement. |
| settler | `address` | The caller. |
| depositBoundPrice | `uint256` | The most a depositor could pay per share (PRICE_SCALE, rounded UP), from the per-swap<br/>limits (E12). 0 when no deposit took part. |
| redeemBoundPrice | `uint256` | The least a redeemer could receive per share (PRICE_SCALE, rounded DOWN). 0 when no<br/>redemption took part. |
| usdcIn | `uint256` | USDC spent by the deposits (sum of fills). |
| sharesMinted | `uint256` | Shares minted to the queue for the deposits. |
| sharesBurned | `uint256` | Shares burned for the redemptions. |
| usdcOut | `uint256` | USDC paid to the queue for the redemptions, net of the exit fee. |
| frozenUntil | `uint64` | 0 when not frozen; else the freeze ends by itself at this time (E17, RB-18). |
| returnAllowed | `bool` | ADMIN let each depositor of this settlement pull its slice in kind (`takeReturn`). |
| holdEndsAt | `uint64` | Appended by `queue`: `time + minHold` at the settlement, the unlock time of every deposit<br/>claim it made. `freezeSettlement` is allowed only before it (shares in their hold). |
