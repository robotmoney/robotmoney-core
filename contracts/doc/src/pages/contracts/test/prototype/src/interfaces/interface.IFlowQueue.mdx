# IFlowQueue

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/2e1997131e58d2aeb047277dce870cd794f04ed7/contracts/test/prototype/src/interfaces/IFlowQueue.sol)

**Inherits:** [IFlowEvents](/contracts/test/prototype/src/interface.IFlowEvents)

**Title:** IFlowQueue

The entry point for timed, netted, forward-priced deposits and redemptions of the one fund (E1, E2, E24-E42).
Authority:
- KEEPER_ROLE: `settle` (keeper-only, E34).
- EMERGENCY_ROLE: self-expiring `pauseQueue` (with cooldown, E39), rate-limited `freezeSettlement` (E49).
- ADMIN_ROLE (timelock): `unpauseQueue`, `setFlowParams`, `releaseSettlement`.
- A request's owner: `cancel` (cutoff + stop windows), `withdrawExpired` (deposits), `giveRedemptionNotice`
(redemptions > `maxRoll`), `redeem`.
- Fund only: `onShutdown()` (releases active escrows on wind-down).
