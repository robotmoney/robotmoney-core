# FlowClaimLib

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/2e1997131e58d2aeb047277dce870cd794f04ed7/contracts/test/prototype/src/lib/FlowClaimLib.sol)

**Title:** FlowClaimLib

Limit-free requests, cancels (with `cancelBuffer` & deposit-stop exits), expiry, redemption notice,
claims, wind-down-aware freeze, and sweep for Step 3f `FlowQueue`.

Ledger rule (E13, RB-22, E52): before any mutation of an owner's queued shares (escrow, held, credit),
`fund.ledgerCheckpoint(owner)` runs first so index snapshots capture pre-change balances.
