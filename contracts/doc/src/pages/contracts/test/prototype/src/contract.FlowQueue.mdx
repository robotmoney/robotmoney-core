# FlowQueue

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/521a5ab8f5ed47b51a888e5ae30c5781ecfe3bbd/contracts/test/prototype/src/FlowQueue.sol)

**Inherits:** [AdminFloorAccessControl](/contracts/lib/abstract.AdminFloorAccessControl), ReentrancyGuardUpgradeable, [GovernedUUPS](/contracts/lib/abstract.GovernedUUPS), [IFlowQueue](/contracts/test/prototype/src/interfaces/interface.IFlowQueue)

**Title:** FlowQueue

The entry point for timed, netted, forward-priced deposits and redemptions of the one fund (Step 3f).

Holds roles, reentrancy lock, governance parameters, and getters; delegates logic across four linked
libraries (`FlowMatchLib`, `FlowCheckLib`, `FlowSettleLib`, `FlowClaimLib`) to stay strictly below EIP-170.
Runs behind its own ERC-1967 proxy (`GovernedUUPS`), under the same upgrade timelock as the fund (E1).

<a id="requestdepositwithpermit-uint256-address-uint256-uint8-bytes32-bytes32"></a>

### requestDepositWithPermit

EIP-2612 single-transaction deposit: the caller signs an off-chain permit for `usdc` (spender = this
queue) and submits only this call. The `permit(msg.sender, address(this), usdc, deadline, v, r, s)`
runs inside a try/catch so a front-run of the permit cannot DoS the deposit; the USDC is then pulled
via `safeTransferFrom` and a deposit request opens exactly as `requestDeposit` does.

```solidity
function requestDepositWithPermit(
        uint256 usdc,
        address owner,
        uint256 deadline,
        uint8 v,
        bytes32 r,
        bytes32 s
    ) external nonReentrant returns (uint256);
```
