[Git Source](https://github.com/robotmoney/robotmoney-core/blob/ac79d56728a2dea0587577373d21e1769e9b563b/contracts/test/prototype/src/FlowTypes.sol)

**Title:** IFlowEvents

Events and errors of the FlowQueue. `IFlowQueue` inherits this, so tests can `emit IFlowEvents.X(...)`.
`NotImplemented(string)` is the file-level error of FundTypes.sol.
