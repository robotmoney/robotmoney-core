# FundState

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/src/lib/FundStorage.sol)

Every piece of `RobotMoneyFund` state outside the OpenZeppelin namespaces, in one struct so the
delegatecall-linked fund libraries (`FundValuationLib`, `FundFlowsLib`, `FundAdminLib`) take one
storage reference per call (§6.1: logic lives in linked libraries to keep the fund under EIP-170).

Step 3d (proposal §4.5, §5.9; eng plan E1, E9, E13, E14, E19, E20). Appended after `rolesBound`:

Appended by fund-extras (scaffold plan §7.4):

**Note:**

- **storage-location:** erc7201:robotmoney.storage.RobotMoneyFund

```solidity
struct FundState {
    AssetConfig[] assets;
    mapping(bytes32 codeHash => bool allowed) codeHashAllowed;
    address usdc;
    uint256 tvlCap;
    uint256 perDepositCap;
    uint256 exitFeeBps;
    address feeRecipient;
    uint256 maxSlippageBps;
    uint256 navDeviationGuardBps;
    bool depositsPaused;
    bool shutdown;
    uint64 lastStepAt;
    uint16[] targetBps;
    Plan plan;
    mapping(uint256 index => uint256) deferredTotal;
    mapping(uint256 index => mapping(address account => uint256)) deferredOf;
    bool rolesBound;
    // ── Step 3d (append-only below this line) ──
    address flowQueue;
    bool flowRoleBound;
    bool seeded;
    uint256 minSeedUsdc;
    uint16 poolShareBps;
    mapping(uint256 index => uint256) positionUnits;
    mapping(uint256 index => uint256) positionClaimTotal;
    mapping(uint256 index => mapping(address account => uint256)) positionClaimOf;
    mapping(uint256 period => uint256) inKindUsed;
    uint256 lastGoodNav;
    uint64 lastGoodNavAt;
    // ── fund-extras (append-only below this line) ──
    uint16 inKindBps;
    uint128 inKindFloorUsdc;
    uint32 inKindPeriod;
    /// @dev The cost of the step that halted the current plan (0 while it never halted, or once an extension
    ///      reopened it). A plan is over budget while its budget left is below it (review B-F5: `costSpent` never
    ///      passes `costBudget` any more, so "spent > budget" can no longer say so).
    uint256 haltCost;
}
```

**Properties**

| Name | Type | Description |
| ---- | ---- | ----------- |
| assets | `AssetConfig[]` | The asset list (§4.1). Indices are stable: deactivated, never removed. |
| codeHashAllowed | `mapping(bytes32 codeHash => bool allowed)` | Adapter runtime code hashes ADMIN approved (ADP-2 / NC-2). A Lending asset whose<br/>adapter code hash is revoked leaves NAV and opens an exclusion record (§4.2). |
| usdc | `address` | The underlying (cached `asset()`). |
| tvlCap | `uint256` | Max `totalAssets()` after a deposit. |
| perDepositCap | `uint256` | Max USDC per deposit. |
| exitFeeBps | `uint256` | Exit fee on realized redeem proceeds (&lt;= 100). |
| feeRecipient | `address` | Exit fee recipient. |
| maxSlippageBps | `uint256` | Deposit / redeem swap floor against TWAP (&lt;= 500, above every basket pool fee). |
| navDeviationGuardBps | `uint256` | ORA-4 band (0 disables; else above every basket pool fee and &lt;= 2 000). |
| depositsPaused | `bool` | EMERGENCY pause of deposit and mint only. |
| shutdown | `bool` | EMERGENCY shutdown: deposits closed, tvlCap 0, until ADMIN `restore`. |
| lastStepAt | `uint64` | Timestamp of the last executed step over all plans (§5.3 step 1). |
| targetBps | `uint16[]` | Persistent end target per asset, index-aligned (pushed 0 on `addAsset`). |
| plan | `Plan` | The current plan (§5.1, §5.5); the latest opened, possibly terminal. |
| deferredTotal | `mapping(uint256 index => uint256)` | Per asset: the amount the fund still owes to `redeemInKind` exits whose leg could not<br/>pay out (§4.4, §5.8 row 7, RB-6). Basket: token units still in the fund's balance.<br/>Lending: USDC still inside the adapter. Never counted in NAV or in any pro-rata leg. |
| deferredOf | `mapping(uint256 index => mapping(address account => uint256))` | Per asset and account: that account's part of `deferredTotal` (`claimDeferred`). |
| rolesBound | `bool` | `bindRebalanceRoles` ran (GOVERNANCE_ROLE and REBALANCER_ROLE bind once, RB-1). |
| flowQueue | `address` | The FlowQueue that holds FLOW_ROLE (`bindFlowRole`, once). address(0) before binding.<br/>`ledgerBalanceOf(flowQueue)` is 0 (E13: the queue's own address has no entitlement). |
| flowRoleBound | `bool` | `bindFlowRole` ran. |
| seeded | `bool` | `seed` ran (E14). Set once, never cleared. |
| minSeedUsdc | `uint256` | Least USDC `seed` accepts (§5.9.5, default `DEFAULT_MIN_SEED_USDC`). |
| poolShareBps | `uint16` | Pool-share rule of §4.5 rule 3 (default `DEFAULT_POOL_SHARE_BPS`). |
| positionUnits | `mapping(uint256 index => uint256)` | Per Lending asset index: total units of that lending position (E9, RB-21). Units are<br/>minted and burned as the fund's position changes, so one unit is always the same<br/>fraction of the position. Holders' units are `positionUnits - positionClaimTotal`. |
| positionClaimTotal | `mapping(uint256 index => uint256)` | Per Lending asset index: units held by position-share claims of past in-kind exits. |
| positionClaimOf | `mapping(uint256 index => mapping(address account => uint256))` | Per Lending asset index and account: that account's claim units (`claimPosition`). |
| inKindUsed | `mapping(uint256 period => uint256)` | Per period index (`block.timestamp / inKindPeriod`, below): lending USDC that left the<br/>venues for in-kind exits in that period, fee included (E20 allowance). |
| lastGoodNav | `uint256` | The last NAV computed while every feed was healthy (E19), USDC 6 decimals. |
| lastGoodNavAt | `uint64` | Its timestamp. |
| inKindBps | `uint16` | In-kind allowance per period, in bps of the fund's lending holdings (E20). |
| inKindFloorUsdc | `uint128` | The allowance is at least this many USDC per period. |
| inKindPeriod | `uint32` | Period length in seconds; `inKindUsed` is keyed by `block.timestamp / inKindPeriod`.<br/>The fund holds these three itself (coordinator ruling 6, proposal §5.9.5), so<br/>`inKindUsed` is keyed by this period, not by the queue's `epochLength`. |
| haltCost | `uint256` |  |
