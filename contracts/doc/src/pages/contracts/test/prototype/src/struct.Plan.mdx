# Plan

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/src/FundTypes.sol)

A rebalance plan (§5.1, §5.5). Stored by the fund; one current plan at a time.

```solidity
struct Plan {
    uint64 id;
    PlanStatus status;
    bytes32 receiptId;
    uint64 startTime;
    uint64 endTime;
    uint16[] startBps;
    uint16[] endBps;
    uint16 startIdleBps;
    uint256 navAtOpen;
    uint256 turnoverUsdc;
    uint256 costBudget;
    uint256 costSpent;
    uint32 stepCount;
}
```

**Properties**

| Name | Type | Description |
| ---- | ---- | ----------- |
| id | `uint64` | 1-based, increments on every `setTargetAndOpenPlan`. 0 = no plan. |
| status | `PlanStatus` | See `PlanStatus`. |
| receiptId | `bytes32` | The applied consensus receipt, or bytes32(0) for a `setTarget` plan. |
| startTime | `uint64` | `block.timestamp` at open. |
| endTime | `uint64` | `startTime + duration`. |
| startBps | `uint16[]` | Per asset (length == assetCount at open): the actual TWAP weight at open,<br/>floor-rounded. Snapshot rule: if NAV at open is 0 the start equals the end. |
| endBps | `uint16[]` | Per asset: the target vector at open (`PlanMath.assetTargets`), index-aligned,<br/>inactive assets 0. Sums to 10 000. |
| startIdleBps | `uint16` | Idle USDC's weight at open: `10 000 - Σ startBps` (absorbs rounding). The<br/>idle path target glides from this to 0. |
| navAtOpen | `uint256` | TWAP NAV at open (USDC, 6 decimals). |
| turnoverUsdc | `uint256` | One-sided planned turnover: `navAtOpen * Σ max(endBps_i - startBps_i, 0) / 10 000`. |
| costBudget | `uint256` | `turnoverUsdc * costBudgetBps / 10 000`, plus any `extendBudget` additions. |
| costSpent | `uint256` | Σ realized step cost (`navBefore - navAfter`, floored at 0) of this plan. |
| stepCount | `uint32` | Number of executed steps in this plan. |
