### swapExactOut

Buy exactly `amountOut` of `tokenOut` for at most `maxAmountIn` of `tokenIn`, paid to `recipient`.
Pulls `maxAmountIn` from the caller, sends the unused input back to the caller, and resets its
allowance to the venue to 0. Reverts if the venue needs more than `maxAmountIn` or the deadline passed.

<i>

Same choreography as the production `swap`: the tick spacing must resolve to a factory pool
(`PoolNotFound`), the router enforces `deadline` and `amountInMaximum`. Pulls `maxAmountIn`, resets the
allowance to 0 after the call, returns the unused input to the caller.

</i>

```solidity
function swapExactOut(
        address tokenIn,
        address tokenOut,
        uint24 fee,
        uint256 amountOut,
        uint256 maxAmountIn,
        address recipient,
        uint256 deadline
    ) external returns (uint256 amountIn);
```
