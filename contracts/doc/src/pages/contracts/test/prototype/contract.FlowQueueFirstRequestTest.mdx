# FlowQueueFirstRequestTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d26015d044a6162bbd93106a89523fa140073356/contracts/test/prototype/FlowQueueFixes.t.sol)

**Inherits:** [FlowQueueFixesBase](/contracts/test/prototype/abstract.FlowQueueFixesBase)

Regression (Twin run of v0.9.0-onevault-upgrade, 2026-11-20): the first request of a queue upgraded in place
from v0.8 must settle. Such a queue never ran the v0.9.0 `initialize`, so its era counter reads 0.
`ensureInitialized` used to raise `windDownEra` to 1 right after the request had recorded era 0, so no round
saw the request (`checkSettle` = Window) and claims treated it as a shutdown-era request. The era now
starts at 0 and only `onShutdown` raises it.
