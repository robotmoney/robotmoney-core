# SimLib

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/d51a8ed56dc72ae8662acc53f88fb090d86e44cb/contracts/test/prototype/sim/SimLib.sol)

Pure helpers of the rebalance simulation (RebalanceSim.t.sol): seeded draws, the approximate normal,
V3 depth and spot conversions. Every draw is a keccak of constants, so a record run and a replay run
make identical calls and touch identical pool ticks and slots.
