# ManifestHarness

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/c8a5162b490e1d50c82ad7f169d4e57d3f29c333/contracts/test/DeployTimelock.t.sol)

**Inherits:** [DeployTimelock](/contracts/script/contract.DeployTimelock)

<i>

Exposes the script's internal manifest writer. `_writeJson` runs only
inside `run()`, which needs a broadcast context and a live chain — so
without this seam the manifest is the one part of the deploy script
that ships untested, and a serialization mistake in it surfaces as a
malformed artifact during a real ceremony.

</i>
