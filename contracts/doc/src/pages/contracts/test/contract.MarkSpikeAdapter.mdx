# MarkSpikeAdapter

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/294ae939cc4db43ac7ec7bac05d27e475246f588/contracts/test/NavGrowthLimiter.t.sol)

**Inherits:** [IPositionAdapter](/contracts/interfaces/interface.IPositionAdapter)

<i>

Mis-marking `IPositionAdapter` test fixture: it custodies real USDC 1:1
but its self-reported `totalAssets()` is `heldUSDC + phantomMark`, where
`phantomMark` is a test lever (`setPhantomMark`) that inflates the
adapter's mark with NO backing USDC — exactly the ORA-6/F-17
over-mark/mis-scale class the §4.3a limiter defends against. Attested
INEXACT so redemptions take the no-revert `_sellProportional` path;
`withdraw` delivers what it actually holds and NEVER reverts on the floor
(a mis-marking adapter cannot realize its inflated mark — the honest
shortfall, not a fault). UNIQUE name to avoid forge-doc re-link.

</i>

<a id="deploy-uint256-uint256"></a>

### deploy

Convert `usdcIn` USDC (transferred to the adapter first, same
choreography as v1 `_allocateTo`) into the adapter's position.

<i>

`onlyVault` (reverts `OnlyVault`). Also reverts on venue failure,
the oracle staleness/deviation guard (asset adapters), and the
implementation exposure cap (e.g. `MorphoAdapter.maxExposure`).

</i>

```solidity
function deploy(uint256 usdcIn, uint256 minValueOut)
        external
        onlyVault
        returns (uint256 valueAdded);
```

**Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| usdcIn | `uint256` | USDC (6-decimal units) the vault has already `safeTransfer`ed. |
| minValueOut | `uint256` | Slippage floor; the adapter MUST revert<br/>`SlippageExceeded` when the realized USDC-denominated value added<br/>is below this (no clamp on the deploy path). |

| Name | Type | Description |
| ---- | ---- | ----------- |
| valueAdded | `uint256` | USDC-denominated increase in `totalAssets()` from this<br/>call. Exact adapters MUST return exactly `usdcIn`. |

### totalAssets

Live USDC-denominated value of the position (principal + accrued

the oracle) on a zero balance (SUP-5).

### isExact
