# DeployTimelockFourVaultsTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/7bae4c9b0cf6849694f16d3874216689595dbf25/contracts/test/DeployTimelock.t.sol)

**Inherits:** [SafeGovernance](/contracts/test/helpers/abstract.SafeGovernance)

The one deployment scheme ships four vaults (rmUSDC, rmPROTO, rmAGENT, rmRWA). The
timelock stage treats each the same way: setRegistry once, EMERGENCY to the emergency
key, ADMIN to the timelock, deployer revoked. These tests use the real vault contracts,
a real Safe and the real timelock.
