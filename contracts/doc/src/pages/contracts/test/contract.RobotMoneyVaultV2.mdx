# RobotMoneyVaultV2

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/2b5d9c4acd4cb83f9e0296cb55ac7ac1f5bacbf6/contracts/test/GovernedUpgradeLifecycle.t.sol)

**Inherits:** [RobotMoneyVault](/contracts/contract.RobotMoneyVault)

<i>

A v2 of rmUSDC with one appended field and a reinitializer, the shape of a real upgrade
that needs a migration step (ADR-0014 §3: a reinitializer runs only as the `data` of a
timelock-executed `upgradeToAndCall`). `onlyUpgradeAuthority` is the pairing every
reinitializer carries: an upgrade installed with empty data leaves it pending, and only the
timelock may run it later.

</i>
