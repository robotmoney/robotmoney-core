# VaultScriptGuardBase

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/58e088ac53759285525112de9eee810ef2094dce/contracts/test/VaultScriptGuards.t.sol)

**Inherits:** [BasketDeployFixture](/contracts/test/helpers/abstract.BasketDeployFixture)

Shared guard and sheet-input cases for the three basket vault scripts. Env vars are
process-wide and forge runs test contracts in parallel, so every case reads its inputs
through a prefix that no other test uses. The unprefixed `run()` guard is covered in
`DeployScriptChainGuards.t.sol`. A subclass supplies the harness and its prefix.
