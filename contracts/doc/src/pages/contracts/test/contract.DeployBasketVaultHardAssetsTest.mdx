# DeployBasketVaultHardAssetsTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/418570cf18d1a61c8b8bc2dbcdc90d0c3ef7c094/contracts/test/DeployBasketVaultHardAssets.t.sol)

**Inherits:** [BasketDeployFixture](/contracts/test/helpers/abstract.BasketDeployFixture)

rmHARD script (core 2008, ADR-0018): a plain BasketVault row for PAXG through the existing `AerodromeSwapAdapter` on its
Aero CL USDC pool, priced from the pool TWAP. No oracle. The script reads the real `config/hard-assets.json`; the pool and
factory doubles are etched at the configured addresses.
