# ReentrantHookToken

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/6b71569d3c7e806e0e2c2cc435012d541d09a217/contracts/test/BasketVault.t.sol)

**Inherits:** [TestERC20](/contracts/test/helpers/contract.TestERC20)

<i>

Basket token that calls back into the vault while the vault pays out (an ERC-777 style hook).
Records the owner's share balance and the total supply at callback time, then tries to
re-enter `redeemInKind`. Core 1665 reentrancy probe.

</i>
