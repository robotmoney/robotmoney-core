# UniV3PositionMockVenue

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/294ae939cc4db43ac7ec7bac05d27e475246f588/contracts/test/UniswapV3AssetPositionAdapter.t.sol)

**Inherits:** [IBasketSwapAdapter](/contracts/interfaces/interface.IBasketSwapAdapter)

<i>

Deterministic IBasketSwapAdapter mock: a fixed-price USDC&lt;->TOKEN venue
with a configurable execution-slippage haircut and an optional
expected-window assertion (to prove the adapter threads the configured
TWAP window into pricing). Pre-funded with both tokens. TEST FIXTURE.

</i>
