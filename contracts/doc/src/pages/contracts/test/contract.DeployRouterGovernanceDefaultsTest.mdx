# DeployRouterGovernanceDefaultsTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/92a6966c4e2c4008e204c9d68b50ae898338c9ca/contracts/test/DeployRouterGovernanceDefaults.t.sol)

**Inherits:** Test

What the governance stage leaves behind, read from the chain: the weight
setter holds router ADMIN_ROLE, router WEIGHT_SETTER_ROLE and the receipt
register's ADMIN_ROLE; the deployer's router WEIGHT_SETTER_ROLE is gone; the
deployer holds the governance contract's ADMIN_ROLE and WEIGHT_SETTER_ROLE
until the timelock stage hands them over.
