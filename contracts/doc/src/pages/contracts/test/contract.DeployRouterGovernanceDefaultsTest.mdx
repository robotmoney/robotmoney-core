# DeployRouterGovernanceDefaultsTest

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/cb1d9cc5d144b8c5c8b47688dd34b616792f0d5e/contracts/test/DeployRouterGovernanceDefaults.t.sol)

**Inherits:** Test

<i>

What the governance stage (DeployRouterGovernance) leaves on a fresh
router: the weight setter holds both router roles, the deployer keeps
router ADMIN_ROLE until stage 11 and no WEIGHT_SETTER_ROLE, and the
deployed bytecode carries no voting surface. The quorum-floor tests this
file used to hold went with the quorum (issue #1698).

</i>
