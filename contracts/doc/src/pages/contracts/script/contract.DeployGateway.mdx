# DeployGateway

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/04c494d92ce87df3b9ba252c17541e08e28fdf97/contracts/script/DeployGateway.s.sol)

**Inherits:** [ExpectedChainGuard](/contracts/script/abstract.ExpectedChainGuard)

**Title:** DeployGateway

Stage 5 of the core deploy (libs, vault, registry, router, gateway).
Deploys RobotMoneyGateway bound to the vault AND the router, asserts
`gateway.router()` is the deployed router and not zero, then authorizes the
deploy agent. The router must exist first: the gateway stores it as an immutable,
so a gateway deployed with a zero router can never route (core 1493).

The IC policy and the consensus receipt bind the gateway address, so they run in
their own stage AFTER this one (`DeployInvestmentCommitteePolicy`).

<i>

Required env vars (all required on every chain, no defaults):
EXPECTED_CHAIN_ID     — mandatory and equal to 8453 on Base mainnet
ADMIN_ADDRESS         — receives DEFAULT_ADMIN_ROLE + ADMIN_ROLE
PAUSER_ADDRESS        — receives PAUSER_ROLE (must differ from ADMIN)
AGENT_ADDRESS         — receives AGENT_ROLE  (must differ from both)
SHARE_RECEIVER_ADDRESS — recipient of minted rmUSDC shares
VAULT_ADDRESS         — the rmUSDC RobotMoneyVault
ROUTER_ADDRESS        — the PortfolioRouter from the router stage, non-zero
AGENT_VALID_UNTIL, AGENT_MAX_PER_PAYMENT, AGENT_MAX_PER_WINDOW,
AGENT_MAX_WITHDRAW_PER_PAYMENT, AGENT_MAX_WITHDRAW_PER_WINDOW — agent policy
DEPLOYMENT_OUT        — output JSON path
USDC is the canonical Base USDC constant on every chain.

</i>

## Constants

### MANIFEST_FILE

Manifest file name the stage driver gives DEPLOYMENT_OUT (scripts/deploy/stage-table.json).

```solidity

```

### DEFAULT_MAX_PER_PAYMENT

In-process test seam defaults. Env runs require every agent cap.

```solidity
uint256 public constant DEFAULT_MAX_PER_PAYMENT = 10_000 * 1e6;
```

### DEFAULT_MAX_PER_WINDOW

Default agent spend cap per window in USDC units (test seam only).

```solidity
uint256 public constant DEFAULT_MAX_PER_WINDOW = 100_000 * 1e6;
```

### DEFAULT_MAX_WITHDRAW_PER_PAYMENT

Default per-payment withdraw cap in raw rmUSDC shares (test seam only).

<i>

Withdraw caps count raw rmUSDC shares, not USDC: the vault's share offset is 18, so
1 USDC (1e6 units) is 1e24 raw shares on a fresh vault. A cap sized in USDC units
would block every withdraw (core 1493).

</i>

```solidity
uint256 public constant DEFAULT_MAX_WITHDRAW_PER_PAYMENT = 10_000 * 1e6 * 1e18;
```

### DEFAULT_MAX_WITHDRAW_PER_WINDOW

Default per-window withdraw cap in raw rmUSDC shares (test seam only).

```solidity
uint256 public constant DEFAULT_MAX_WITHDRAW_PER_WINDOW = 100_000 * 1e6 * 1e18;
```

### DEFAULT_VALID_UNTIL_OFFSET

Default agent authorization lifetime from deployment (test seam only).

```solidity
uint64 public constant DEFAULT_VALID_UNTIL_OFFSET = 30 days;
```
