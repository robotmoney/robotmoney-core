# Request

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/686fb6eee37ebea70d3c4d3ec214392afc74d9f7/contracts/FlowTypes.sol)

One forward-priced request (E25, E40, E41, E52).

```solidity
struct Request {
    address owner;
    RequestKind kind;
    uint64 epoch;
    uint256 amount;
    uint256 remaining;
    bool closed;
    uint16 exitFeeBps;
    uint32 minHold;
    uint16 maxRoll;
    uint64 createdAt;
    uint64 expiryEpoch;
    uint64 expiresAt;
    uint64 noticeRound;
    uint64 era;
    bool enrolled;
    uint256 matchCycle;
    uint256 normBasis;
    uint256 entryCumScaled;
    uint256 entryUnmatchedFactor;
    uint256 nextMatchId;
}
```

**Properties**

| Name | Type | Description |
| ---- | ---- | ----------- |
| owner | `address` | Owns the request and every claim from it. Named by the caller; never changed. |
| kind | `RequestKind` | Deposit or Redeem. |
| epoch | `uint64` | Epoch index the request was made in. |
| amount | `uint256` | Escrowed at the request: USDC (Deposit) or shares (Redeem). |
| remaining | `uint256` | Last synced unfilled escrow (views compute current live remaining from match index). |
| closed | `bool` | Nothing is left in escrow for this request. |
| exitFeeBps | `uint16` | Redeem only: Fund `exitFeeBps` snapshotted at creation (E41). |
| minHold | `uint32` | Deposit only: Queue `minHold` snapshotted at creation (E41). |
| maxRoll | `uint16` | Queue `maxRoll` snapshotted at creation (E41). |
| createdAt | `uint64` | Timestamp at creation (for deposit-stop cancel window check). |
| expiryEpoch | `uint64` | `epoch + maxRoll` at creation. |
| expiresAt | `uint64` | Deposit: end of `expiryEpoch`; Redeem: `type(uint64).max` (never expires). |
| noticeRound | `uint64` | Redeem only: target round epoch when `giveRedemptionNotice` was given (0 = none). |
| era | `uint64` | Queue wind-down era when created (`windDownEra`). |
| enrolled | `bool` | True once enrolled into the active match pool. |
| matchCycle | `uint256` | Cycle in which this request enrolled (`depCycle` or `redCycle`). |
| normBasis | `uint256` | Factor-normalized escrow basis in `matchCycle`. |
| entryCumScaled | `uint256` | Redeem only: tier cumulative USDC per normBasis at last sync/enroll. |
| entryUnmatchedFactor | `uint256` | Unmatched factor at creation/enroll/last sync (Redeem). |
| nextMatchId | `uint256` | Deposit only: next `depMatches` index to materialize for this request. |
