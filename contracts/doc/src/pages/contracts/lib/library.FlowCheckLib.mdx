# FlowCheckLib

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/686fb6eee37ebea70d3c4d3ec214392afc74d9f7/contracts/lib/FlowCheckLib.sol)

**Title:** FlowCheckLib

Pre-trade oracle, TWAP, venue liquidity, and breaker checks (Steps 1–7) plus forward-priced terms
quotes (`quoteDeposit` / `quoteRedeem`). Linked (`public`) to keep `FlowQueue` under G1.
