**Title:** FlowSettleLib

Keeper-only round settlement (E34, E35): StepInWindow gate + notice cleanup + enrollment +
round-stop venue test + O(1) Whole Match `M` + FIFO net-side execution (`sellForFlowGross` / `mintInKind`).
