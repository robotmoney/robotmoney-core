# IBasketValuation

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/2b5d9c4acd4cb83f9e0296cb55ac7ac1f5bacbf6/contracts/lib/BasketSwapOps.sol)

<i>

The two TWAP valuation views of `BasketVault` the swap legs price their floors with. The
library runs as the vault (DELEGATECALL), so these are self-calls to the vault's own views,
and the floors are exactly the ones the vault computed inline before ADR-0014.

</i>
