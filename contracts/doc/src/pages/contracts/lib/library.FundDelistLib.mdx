# FundDelistLib

[Git Source](https://github.com/robotmoney/robotmoney-core/blob/5caec0de0f4306dd0140efcb9fb7b38bed8daae4/contracts/lib/FundDelistLib.sol)

**Title:** FundDelistLib

Delisting sales, delisting claim accumulators, asset admission rules 4/6/7 helpers, and
initialization with ledger creation for `RobotMoneyFund`, linked externally via DELEGATECALL
to preserve EIP-170 headroom. Custody (`safeTransfer` / `forceApprove`) stays in `FundFlowsLib` / `RobotMoneyFund` (G1).
