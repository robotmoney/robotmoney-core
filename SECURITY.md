# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by email:

- `security@robotmoney.net`

Do not open a public GitHub issue for a suspected exploitable vulnerability.
Include the affected component, impact, reproduction steps, and any relevant
transaction hashes, addresses, logs, or screenshots.

## Response Commitment

The Robot Money maintainers aim to acknowledge new vulnerability reports within
72 hours and provide a triage update within 7 calendar days.

Critical reports that indicate active loss of funds, private-key compromise, or
production exploitability should be marked `CRITICAL` in the email subject.

## Scope

The current bug-bounty scope is maintained in
[`docs/bug-bounty.md`](docs/bug-bounty.md). That document is the canonical place
for in-scope components, exclusions, severity guidance, and deployment-address
references.

## Safe Harbor

Good-faith security research is welcome when it stays within the published
scope, avoids privacy violations, avoids service disruption, and does not
attempt to access or move funds that do not belong to the researcher.
